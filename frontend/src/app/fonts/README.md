# Fontes locais

Arquivos oficiais do Google Fonts, obtidos em 2026-10-03. O frontend usa
`next/font/local`: desenvolvimento e build não consultam Google Fonts.
Os arquivos WOFF2 são versionados e servidos pelo próprio aplicativo.

O subconjunto Latin cobre os textos em português e inglês, incluindo os
acentos portugueses. IBM Plex Sans e Source Serif 4 usam arquivos variáveis;
IBM Plex Mono mantém os pesos 400 e 500. As famílias, estilos e pesos
configurados no layout preservam a tipografia do sistema.

Licenças SIL Open Font License 1.1 incluídas por família nos arquivos `*-OFL.txt`.
Para atualizar, obtenha os arquivos oficiais, preserve as licenças e atualize
os hashes abaixo. Nenhum download de fontes deve ser adicionado ao CI.
